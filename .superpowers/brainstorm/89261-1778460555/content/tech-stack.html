What tech stack for the web app?

The agent pipeline stays the same — we're choosing how to wrap it in a web interface

A

Python + FastAPI + plain HTML

A lightweight Python web server that calls the agent pipeline and returns results. No JavaScript framework — just HTML forms and a results page. Easiest to set up, runs locally, stays close to what you already built.

  • One language (Python) end to end
  • No frontend build step
  • Runs on localhost with one command
B

Python + FastAPI + React (Next.js)

A proper full-stack app: FastAPI backend exposes an API endpoint, Next.js frontend calls it and renders a polished UI with loading states. More work to set up but looks production-ready.

  • Best visual result
  • Requires Node.js + npm
  • Two servers to run (API + frontend)
C

Python + Gradio

Gradio is a Python library that builds a web UI automatically from your Python function — zero HTML/CSS/JS. You pass the pipeline function and Gradio generates a clean interface. Very popular in AI/ML demos.

  • Fewest lines of code (~20)
  • Built-in streaming support
  • Easy to share publicly via Hugging Face Spaces
